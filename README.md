# 中医数字伴侣 Agent

面向高负荷独立执业中医的专业数字分身方案。

## 核心场景

长期调理患者复诊前的信息收集与状态回顾。

## 产品边界

- 先建设并治理最小知识切片，通过知识就绪门禁后再启用专业分身。
- 专业分身只收集当前任务缺失的事实、调用获权内容并生成未发送草稿。
- 辨证、诊断、治疗方案、复诊建议和正式发送均由医生完成。
- 患者原话、病历、报告、舌象和诊疗轮次属于业务记录，不自动进入知识库。
- 业务记录只有经过授权、脱敏、分类和人工审核后，才能成为正式知识或专业能力。
